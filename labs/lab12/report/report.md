# Контрольные вопросы

1. **Почему важна точная синхронизация времени для служб баз данных?**  
   Корректное время необходимо для согласованности транзакций, репликации и журналирования. Несовпадение меток времени может привести к повреждению данных, неправильному порядку операций и сбоям при кластерной работе.

2. **Почему служба проверки подлинности Kerberos сильно зависит от правильной синхронизации времени?**  
   Kerberos использует временные метки в тикетах. Если время на клиентах и серверах отличается больше чем на несколько минут, тикеты считаются недействительными, и аутентификация не проходит.

3. **Какая служба используется по умолчанию для синхронизации времени на RHEL 7?**  
   По умолчанию используется служба **chronyd**.

4. **Какова страта по умолчанию для локальных часов?**  
   Локальные (аппаратные) часы по умолчанию имеют **stratum 10**.

5. **Какой порт брандмауэра должен быть открыт, если вы настраиваете свой сервер как одноранговый узел NTP?**  
   Необходимо открыть порт **123/UDP**.

6. **Какую строку нужно включить в конфигурационный файл chrony, если вы хотите быть сервером времени, даже если внешние серверы NTP недоступны?**  
   Требуется включить директиву: `local stratum 10`

7. **Какую страту имеет хост, если нет текущей синхронизации времени NTP?**  
При отсутствии синхронизации хост также переходит в режим **stratum 10**.

8. **Какую команду можно использовать на сервере с chrony, чтобы узнать, с какими серверами он синхронизируется?**  
Используется команда: `chronyc sources`

9. **Как можно получить подробную статистику текущих настроек времени для процесса chrony?**  
Для просмотра детальной информации используется команда: `chronyc tracking`
