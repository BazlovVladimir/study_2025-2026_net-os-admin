# Контрольные вопросы

1. **Поясните принцип работы Fail2ban.**
   Fail2ban отслеживает журналы системных сервисов (SSH, Apache, Postfix и др.) и анализирует события, связанные с неуспешными попытками аутентификации или подозрительной активностью. Если количество ошибок от определённого IP-адреса превышает заданный порог, Fail2ban автоматически применяет действие — чаще всего добавляет правило в firewall, блокирующее доступ нарушителя на заданный период времени.

2. **Настройки какого файла более приоритетны: jail.conf или jail.local?**
   Более приоритетным является файл **jail.local**.
   Файл *jail.conf* содержит настройки по умолчанию и не должен изменяться.
   Файл *jail.local* или файлы в `/etc/fail2ban/jail.d/` позволяют переопределять параметры и применяются поверх конфигураций по умолчанию.

3. **Как настроить оповещение администратора при срабатывании Fail2ban?**
   Для уведомлений используется параметр действия (`action`).
   Чтобы включить отправку email-оповещений, необходимо выбрать действие, содержащее отправку почты, например:

   * `action_mw` — отправляет предупреждение и лог нарушения;
   * `action_mwl` — отправляет предупреждение и полный лог файла, вызвавшего блокировку.
     В разделе jail достаточно указать нужное действие и email администратора через параметр `destemail`.

4. **Поясните построчно настройки по умолчанию веб-службы в /etc/fail2ban/jail.conf.**
   Для веб-служб обычно определены jails, реагирующие на различные виды атак: подбор паролей, вредоносные боты, выполнение скриптов и уязвимости типа shellshock.
   Основные параметры:

   * **enabled** — включение/отключение защиты;
   * **port** — порты, которые связаны с веб-службой;
   * **filter** — имя фильтра, определяющего шаблоны атак в логах;
   * **logpath** — пути к журналам веб-сервера;
   * **maxretry, findtime, bantime** — условия срабатывания блокировки.
     Эти параметры позволяют Fail2ban отслеживать подозрительные HTTP-запросы и блокировать злоумышленников.

5. **Поясните построчно настройки по умолчанию почтовой службы в /etc/fail2ban/jail.conf.**
   Для почтовых служб (Postfix, Dovecot, SASL) в конфигурации содержатся параметры:

   * **enabled** — включение конкретного jail’a;
   * **port** — порты SMTP/IMAP/POP3;
   * **filter** — шаблон поиска ошибок входа и злоумышленной активности;
   * **logpath** — файл журнала почтового сервера;
   * **maxretry** — число неуспешных попыток;
   * **bantime** — время блокировки.
     Эти параметры позволяют Fail2ban защищать почтовый сервер от перебора паролей, атак через SASL и спам-активности.

6. **Какие действия может выполнять Fail2ban при обнаружении атакующего IP-адреса? Где посмотреть их описание?**
   Fail2ban может:

   * блокировать IP через firewall (обычно firewalld или iptables);
   * отправлять уведомления администратору;
   * выполнять пользовательские скрипты;
   * писать в лог дополнительные сообщения;
   * изменять конфигурацию сервисов при необходимости.
     Все действия описаны в каталоге **/etc/fail2ban/action.d/**, где каждая конфигурация представляет готовый набор действий, доступный для использования в jail’ах.

7. **Как получить список действующих правил Fail2ban?**
   Это можно сделать через команду клиента Fail2ban:
   **fail2ban-client status**
   Она выводит список всех активных jail’ов.
   Для отдельного jail’a отображаются текущие и общие статистические данные, включая заблокированные IP.

8. **Как получить статистику заблокированных Fail2ban адресов?**
   Для конкретного jail’a используется команда:
   **fail2ban-client status <jail>**
   В выводе видно:

   * количество заблокированных IP;
   * список текущих блокировок;
   * общее число блокировок.

9. **Как разблокировать IP-адрес?**
   Для снятия блокировки используется команда:
   **fail2ban-client set <jail> unbanip <адрес>**
   После выполнения команда выводит обновлённый список, подтверждая снятие бана.
