# Контрольные вопросы

1. **Какая команда отвечает за настройки безопасности в MariaDB?**
   За выполнение базовой настройки безопасности отвечает команда **`mysql_secure_installation`**.
   Она позволяет задать пароль root, удалить тестовые базы данных и анонимных пользователей, запретить удалённый доступ root и обновить привилегии.

2. **Как настроить MariaDB для доступа через сеть?**
   Для сетевого доступа необходимо изменить параметр `bind-address` в конфигурационном файле MariaDB:

   * указать `0.0.0.0` — для доступа со всех узлов,
   * или конкретный IP-адрес — для ограниченного доступа.
     Кроме того, пользователю MariaDB нужно выдать права с хостом `'%'` или нужным IP-адресом.

3. **Какая команда позволяет получить обзор доступных баз данных после входа в среду оболочки MariaDB?**
   Для отображения списка баз данных используется команда **`SHOW DATABASES;`**

4. **Какая команда позволяет узнать, какие таблицы доступны в базе данных?**
   После выбора базы командой `USE database;` таблицы отображаются через **`SHOW TABLES;`**

5. **Какая команда позволяет узнать, какие поля доступны в таблице?**
   Структура таблицы выводится командой **`DESCRIBE table_name;`**

6. **Какая команда позволяет узнать, какие записи доступны в таблице?**
   Для просмотра содержимого таблицы используется запрос в виде **`SELECT * FROM table_name;`**

7. **Как удалить запись из таблицы?**
   Удаление выполняется командой вида:
   **`DELETE FROM table_name WHERE условие;`**

8. **Где расположены файлы конфигурации MariaDB? Что можно настроить с их помощью?**
   Основные конфигурационные файлы находятся в:

   * `/etc/my.cnf`
   * `/etc/my.cnf.d/`

   С их помощью можно настроить:

   * кодировку,
   * параметры сетевого доступа,
   * пути журналов,
   * поведение клиента и сервера MariaDB,
   * плагины и кеши,
   * параметры оптимизации.

9. **Где располагаются файлы с базами данных MariaDB?**
   Файлы баз данных по умолчанию хранятся в каталоге:
   **`/var/lib/mysql/`**

10. **Как сделать резервную копию базы данных и затем её восстановить?**
    Резервное копирование выполняется с помощью `mysqldump`:

* полная копия:
  `mysqldump -u root -p database > backup.sql`
* сжатая копия:
  `mysqldump -u root -p database | gzip > backup.sql.gz`

Восстановление выполняется командами:

* из обычного файла:
  `mysql -u root -p database < backup.sql`
* из сжатого:
  `zcat backup.sql.gz | mysql -u root -p database`
